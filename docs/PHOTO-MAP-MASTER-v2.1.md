# PHOTO MAP — MASTER v2.1

## Regra permanente
Fotografia real descreve somente o que é confirmado pela própria imagem ou por informação fornecida pelo Colégio. Não inferir série, etapa, idade escolar, cargo de adulto ou nome de atividade.
