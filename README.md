# Colégio Perini — V5.4 Polimento de Design Final

Versão final pronta para subir, construída a partir da V5.3.

## O que esta versão corrige

- Mantém a copy e a arquitetura aprovadas.
- Aplica polimento de designer sem reiniciar o site.
- Mantém o hero limpo, com apenas um CTA principal.
- Preserva os ciclos enriquecidos.
- Ajusta a prova rápida para funcionar como 2x2 no mobile.
- Melhora crops e alturas de fotos no mobile para evitar corte ruim de aluno, corpo, rosto ou ação pedagógica.
- Mantém mapa e contato como fechamento de conversão.
- Mantém o Sistema COC e o Ensino Médio com conteúdo pedagógico.

## Como publicar

Suba o conteúdo desta pasta na raiz do GitHub/Vercel/Netlify.

Arquivos principais:

- `index.html`
- `css/perini.css`
- `js/site.js`
- `assets/`
- `robots.txt`
- `sitemap.xml`
- `manifest.webmanifest`
- `vercel.json`

## Validação final humana

Abrir `ABRIR_PREVIEW_LOCAL.html` ou `index.html` e conferir visualmente:

- Desktop 1440px;
- Notebook 1366px;
- Tablet 768px;
- Mobile 430px;
- Mobile 390px.

A aprovação final de fotografia deve ser visual.
